# Instrucciones

## Requerimientos

***backend***

- Python 3.10

***frontend***

- Java Script
- HTML y CSS

## Como Iniciar

### Backend  y Frontend

Crear un carpeta para clonar el repositorio

```mkdir Oh_Sansi```

abrir el directorio de la carpeta creada 

```cd Oh_Sansi```

crear el entorno virtual

```python -m venv .venv```

abrir el entorno virtual

```./.venv/Scripts/activate```

intalar las dependencias

```pip install -r requirements.txt```

Para la base de datos las instrucciones se encuentran en intrucciones-bd.txt y OH_SANSI_DB.txt(Es el script que tiene que ejecutarse en algun administrador de Base de Datos para poder importar los datos principales del proyecto).
 
### Ejecutar el siguiente commando para que el programa funcione de formal local:

```python run.py```
